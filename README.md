# Age Calculator

## Project Description
A simple Python application to calculate exact age from date of birth.

## Features
- Calculates age in years, months and days.
- Handles leap years.
- Validates date of birth.
- Prevents future dates.

## Technologies Used
- Python
- Datetime Module
- Calendar Module

## How to Run
python age_calculator.py
